# Sistema Academia Frontend

Front-end React moderno para o sistema de academia.

## Instalação

1. Navegue para o diretório frontend:
   ```
   cd frontend
   ```

2. Instale as dependências:
   ```
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```
   npm run dev
   ```

O front-end estará disponível em `http://localhost:3000`.

## Funcionalidades

- **Login**: Autenticação com CPF e senha.
- **Dashboard Professor**:
  - Gerenciar alunos (listar, cadastrar, desativar).
  - Criar treinos para alunos.
  - Visualizar e finalizar pedidos de treino.
- **Dashboard Aluno**:
  - Visualizar treino atual.
  - Pedir novo treino com observações.

## Design

Interface minimalista com cores neutras, focada na usabilidade.
